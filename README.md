# Ecommerce-data-analytics-portfolio
Final project submission for Dicoding's "Belajar Fundamental Analisis Data" course. Features exploratory data analysis (EDA), data wrangling, and an interactive Streamlit dashboard.
## 🚀 Persiapan & Setup Proyek
👉 [Lihat Proses & Tahapan Analisis Keseluruhan](Proccess.md)


### 1. Inisialisasi Environment
Clone repository ini dan install seluruh dependensi yang dibutuhkan:
- Python (versi 3.9+)
- Pipenv (jika belum ada, install via terminal: `python -m pip install pipenv`)
- Silakan clone [Repositori Data Analytics](https://github.com/Novelorenta09/Ecommerce-data-analytics-portfolio.git) ini.

### 2 Setup Terminal
```
- mkdir proyek_analisis_data
- cd proyek_analisis_data
- python -m pipenv install
- python -m pipenv shell
- pip install numpy pandas scipy matplotlib seaborn jupyter
- jupyter-notebook .
```
